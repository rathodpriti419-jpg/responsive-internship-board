## Features

### 1. Responsive Design

The website works on:

- Mobile
- Tablet
- Desktop

CSS media queries are used to change the layout for different screen sizes.

### 2. Internship Cards

Internship information is displayed using reusable cards.

Each card contains:

- Internship title
- Company name
- Domain
- Location
- Duration
- Internship type
- Description
- Required skills
- View Details button

### 3. Search

Users can search internships by:

- Internship title
- Company
- Domain
- Location
- Skills
- Description

### 4. Domain Filter

Users can filter internships by domain:

- Web Development
- Mobile Development
- Python
- Data Science
- UI/UX Design
- Cloud Computing

### 5. Empty State

If no internship matches the search or filter, the website displays:

"No internships found"

Users can click "Show all internships" to reset the results.

### 6. Error State

An error message is included for cases where internship data cannot be loaded.

### 7. Accessibility

The project includes:

- Semantic HTML
- Labels for form controls
- Accessible buttons
- Keyboard focus styles
- ARIA labels
- Live result updates
- Keyboard shortcut for search
- Escape key to clear filters

### 8. No Framework

This project uses:

- HTML
- CSS
- JavaScript

No React, Bootstrap, Tailwind or other framework is used.

No installation is required.

## Keyboard Accessibility

### Tab

Use Tab to move through buttons, links and form controls.

### Enter / Space

Use Enter or Space to activate focused controls.

### /

Press `/` to quickly focus the search box.

### Escape

Press Escape while using a form control to clear the filters.
